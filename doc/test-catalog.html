Test Catalog

Every test case in the suite, grouped by category. A program is one source file testing one vulnerability; a record is one entry in configure.json, which is a program combined with a particular set of compile-time macros. One program therefore yields several records wherever it is exercised in different memory regions or in both the overflow and underflow directions.

The registry is authoritative and this page mirrors it: the program names and record names below are checked against configure.json in both directions, so a case added to or removed from the registry without a matching edit here is a failure rather than a silent drift.

Two things to know when reading the tables. A record's name does not always start with its program's name: cfi-code-injection serves twelve records named {call,jump,return}-instruction-in-*, and each jump-func-ra-from-heap-memcpy-* program also provides its acc-copy-stackra-to-heap-* prerequisite. And acc-read-func.gen is the one program whose target is generated by the Makefile from a built binary rather than compiled from a .cpp of the same name.
